# Regex Sandbox

An interactive regex testing tool built with HTML, CSS, and JavaScript.

This project allows users to experiment with regular expressions in a simple and user-friendly environment. Enter a regex pattern, select flags, provide a test string, and instantly see highlighted matches along with the matching results.

## Features

- Create and test custom regular expressions
- Support for Global (`g`) and Case-Insensitive (`i`) flags
- Real-time regex matching
- Highlight matched text within the test string
- Displays all matches found
- Handles multiple matches
- Displays "no match" when no results are found
- Clean and responsive user interface

## Technologies Used

- HTML5
- CSS3
- JavaScript (ES6)

## How It Works

1. Enter a regular expression pattern.
2. Select any desired flags (`g` and/or `i`).
3. Enter text into the test string area.
4. Click the **Test Regex** button.
5. Matching text will be highlighted and displayed in the results section.
